# GitHub publishing checklist

This source is prepared for version control but is not yet authorized for public
release.

- [ ] Confirm repository owner and whether it belongs to an individual, lab, or
  Texas A&M organization.
- [ ] Obtain approval from Vishnu Saj and Dr. Moble Benedict.
- [ ] Confirm contributor names and attribution.
- [ ] Select a license with the research team; none has been assumed here.
- [ ] Confirm no sponsor, export-control, NDA, or unpublished-research restriction.
- [ ] Scan history and files for credentials, tokens, machine paths, and private data.
- [ ] Keep raw flight/SITL logs and large CSV/ZIP outputs outside ordinary Git history.
- [ ] Enable branch protection, required CI, and pull-request review.
- [ ] Create a tagged release that identifies the exact validated source revision.
- [ ] Add DOI/archive metadata only after authorship and release approval.
